# Retail-sales-profitability-analysis-
Retail Sales and Profitability Analysis
Project Overview
This project analyses retail sales data to identify trends in sales, profitability, product performance, and regional performance.
Objectives

Assess overall sales and profit.
Identify the best- and worst-performing product categories.
Examine regional sales and profitability.
Investigate the relationship between discounts and profit.
Develop evidence-based business recommendations.

Tools

Microsoft Excel
Python
SQL
Power BI

Project Status
In progress.
